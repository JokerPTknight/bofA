*************************
 KNOWN INCOMPATIBILITIES
*************************

1. High Resolution Video Cards: On some high resolution
   video cards set to 256 or more colors, the displayed
   colors may be incorrect in other applications after
   running BofA's HomeBanking with Managing Your Money
   (BOFAMYM).  To correct this condition, simply 
   restart the other application.

2. Windows 95/Windows NT users: Win95 or Windows
   NT users will not be able to use the Clock and
   Calendar features in BOFAMYM.  The Clock.exe 
   and Calendar.exe files are no longer included 
   in these Windows installations. If Win95 or NT
   is installed as an upgrade from Windows 3.x 
   these features may be available, but users
   must reconfigure the path statements by selecting
   Menu Setup from the Tools Menu in BOFAMYM.

3. Modem Problems:
 
   a. The following modems have been identified for 
      having an older version chipset which is not 
      compatible with obtaining a Local Access Number.
      The modems identified so far are:  
          Packard Bell 14.4
          Zoom 14.4 PCMCIA
          GVC 14.4
      Whether or not you have one of the modems listed 
      above, if during "Obtain Access Number" you 
      receive an 801 or 810 Error Code please call 
      Customer Service (for the phone number, see 
      User's Guide, Appendix E).  For all other problems 
      please refer to Help for steps to correct the 
      problem.

   b. IBM ThinkPad Models 755 and 760 or IBM Aptiva 
      models which have MWave modem,  may require an 
      upgrade to the modem drivers.  If you have a 
      problem connecting to the Bank, please call 
      Customer Service for instructions on updating 
      the drivers.
 
4. Print Checks:
 
   a. Citizen 180D printers and some Panasonic printers
      do not print multiple pin-feed checks correctly
      with the Windows printer drivers that were 
      available at the release of BOFAMYM. You can
      either print one check at a time, or set the
      printer to emulate another printer such
      as Epson.
         
   b. HP Deskjet 500 driver may produce check 
      alignment problems when running under Windows
      95. Replacing the HP Deskjet 500 driver with
      the HP Deskjet 510 driver should eliminate the
      problem.

5. DISPLAYING GRAPHS - BofA's HomeBanking with Managing 
   Your Money for Windows uses a program called GSW.EXE 
   for displaying graphs.  If another application which 
   uses GSW.EXE is installed AFTER the installation of 
   BofA's HomeBanking with Managing Your Money, you may 
   be unable to display graphs.  (The other program may 
   use an incompatible version of GSW.EXE).  To correct 
   this condition, rename the GSW.EXE and GSWDLL.DLL 
   files in your Windows/System directory to GSW.OLD 
   and GSWDLL.OLD respectively, and then reinstall 
   BofA's HomeBanking with Managing Your Money for 
   Windows.

6. If a "General Application Error" is received please
   record what you were doing prior to the error 
   occurring.  Repeat the steps that caused the error.  
   If the error still persists, please contact Customer
   Service (for the phone number, see User's Guide, 
   Appendix E).  Note: This error is NOT the same as 
   a Windows General Protection Fault (GPF), and is 
   almost always harmless.
